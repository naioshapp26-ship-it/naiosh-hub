# Naiosh Hub 360

غرفة العمليات المركزية لإمبراطورية نايوش — Imperial Edition.

## التشغيل

```bash
npx serve . -l 3600
```

ثم افتح: http://localhost:3600

## الصفحات

- `index.html` — الواجهة الرئيسية (نفس روح تصميم Naiosh ERP)
- `login.html` — تسجيل الدخول
- `dashboard.html` — غرفة العمليات (8 طبقات)
