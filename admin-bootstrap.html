تهيئة حساب الإدارة

هذه الصفحة تعمل مرة واحدة فقط عندما لا يكون حساب naioshhub@example.com مهيأً بعد.

الحساب مهيأ بالفعل.

الذهاب لتسجيل الدخول
  1. افتح Railway → الخدمة → Variables
  2. الأسهل: أضيفي HUB_SUPER_ADMIN_INITIAL_PASSWORD ثم Redeploy — بعدها ارجعي لصفحة الدخول مباشرة.
  3. أو من Deployments → View Logs انسخي سطر [HUB BOOTSTRAP] One-time setup code والصقيه أدناه.
