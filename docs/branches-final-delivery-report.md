تاريخ التحقق: 2026-10-12  
الموقع المنشور: `https://naiosh-hub-production.up.railway.app`  
الدمج: PR #223 (OSM/Leaflet) + PR #224 (حفظ حجوزات الحاضنة/المكتب + GET للمسؤول)

## خدمة الخرائط المستخدمة

| الطبقة | الخدمة | تكلفة مباشرة |
|---|---|---|
| خريطة تفاعلية | **Leaflet 1.9** + بلاطات **OpenStreetMap** | بدون مفتاح API |
| تحويل جغرافي (بلد/مدينة) | **Nominatim** عبر `/api/hub/geo/reverse` (حد معدّل + كاش) | بدون مفتاح |
| بديل اختياري | Google Maps + Geocoding إن وُجدت `GOOGLE_MAPS_*` | حسب تسعير Google |

الكتابة اليدوية لاسم الفرع/البلد **دائمًا متاحة** إذا رُفض إذن الموقع أو تعطّلت الخريطة.

## إجمالي الصفحات/النماذج التي رُوجعت

| المجموعة | العدد | نجح فعليًا على الإنتاج |
|---|---|---|
| صفحات عميل مع خريطة OSM (×3 عروض) | 5 صفحات × فحوصات متعددة | نعم (24 صف OSM + إرسال حاضنة) |
| API geo + حفظ حجز | نعم | نعم |
| هوية / إعلانات (واجهة موظف) | نعم محليًا | **لم يُثبت على الإنتاج** |
| مهام / عملاء / موظفين / لوحة تحكم (نماذج geo داخل modals) | مراجعة كود + جزئي | **لم تُختبر إرسالًا كاملًا على الإنتاج** |
| `my-branch.html` | عرض منح — بدون كتالوج | نعم (لا يوجد picker) |
| `side-projects` دولة قانونية | select دولة (ليس فرع) | مقبول كما هو |

**لا FULL PASS للمنصة كاملة** — بسبب:
1. إعادة فتح المسؤول على الإنتاج غير مثبتة (401 لكلمة مرور البيئة).
2. نماذج الإدارة داخل dashboard (مهام/عملاء/موظفين/تعديل فرع) لم تُمرَّر إرسالًا كاملاً على الموقع المنشور بجلسة موظف.
3. إذن الموقع الحقيقي من المتصفح (موافقة المستخدم) لا يُختبر في headless؛ مسار الرفض اختُبر.

## ما يعمل بثقة على الموقع المنشور الآن
- لا قوائم فروع جاهزة في نماذج العميل المختبرة.
- كتابة حرة لاسم الفرع/البلد.
- خريطة OSM حقيقية قابلة للنقر مع استخراج بلد/مدينة.
- الحفظ في الخادم مع الإحداثيات لطلبات الحجز (حاضنة/منصة عبر API).
- رفض الموقع لا يمنع الإكمال اليدوي.

  `BASE_URL=https://naiosh-hub-production.up.railway.app node scripts/e2e-branches-prod-submit-reopen.js`
