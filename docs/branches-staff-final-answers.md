# إجابات نهائية — فروع + دخول الموظف (إنتاج)

التاريخ: 2026-10-12  
الموقع: `https://naiosh-hub-production.up.railway.app`

## 1) هل تسجيل دخول الموظف يعمل؟

**نعم — عبر حساب اختبار محدود مصرّح به.**

| الحساب | النتيجة |
|---|---|
| `naioshhub@example.com` + `HUB_SUPER_ADMIN_INITIAL_PASSWORD` | **فشل 401** — الحساب موجود؛ الهاش في Postgres لا يطابق متغير البيئة (كلمة المرور تغيّرت بعد التهيئة). **لم نُغيّر كلمة مرور الحساب الحقيقي.** |
| `e2e-branches@naiosh.test` (صلاحيات محدودة EMP-E2E-BR) | **نجاح 200** بعد نشر bootstrap الاختبار |

## 2) هل بيانات العميل تظهر للمسؤول؟

**نعم.** بعد دخول موظف الاختبار:

- إنشاء حجز حاضنة بفرع+بلد+مدينة+إحداثيات → `201`
- `GET /api/hub/platform-bookings?id=…` يعيد نفس القيم للمسؤول
- مثال مؤكد: `pb-mv5qntbb-en01k` → فرع/الأردن/عمّان/`31.9539,35.9106`

الحجوزات تُحفظ الآن في `hub_meta` (متين عبر إعادة النشر). الحجوزات القديمة التي كانت على قرص مؤقت قبل هذا التحسين قد لا تكون موجودة بعد إعادة النشر.

## 3) هل جميع نماذج الفروع تعمل على الإنتاج؟

| السطح | النتيجة على الإنتاج |
|---|---|
| صفحات العميل + خريطة OSM | ناجح (سابقًا + مستمر) |
| حجز حاضنة حفظ/إعادة فتح للمسؤول | ناجح |
| المهام: فرع نص حر + حفظ | ناجح (`تم حفظ المهمة`) |
| إضافة فرع (ERP): كتابة حرة + دولة بدون قائمة + geo | ناجح |
| صفحة الفروع العامة + Leaflet | ناجح |
| العملاء: لا select كتالوج فروع | ناجح |
| الهوية/الموظفين: لا select كتالوج فروع | ناجح (لا قوائم قديمة ظاهرة) |

## 4) هل بقي أي نموذج غير مختبر أو به مشكلة؟

- **دخول القائد الأعلى بمتغير البيئة:** ما زال فاشلًا عن قصد (لا إعادة ضبط بدون إذن). استخدم حسابك الحقيقي من المتصفح أو اضبط سرّ `HUB_E2E_STAFF_PASSWORD` بدل الاعتماد على الـ fallback الاختباري.
- **واجهة ملف 360 / جداول الحجوزات البصرية داخل لوحة معيّنة:** الإثبات تم عبر API المسؤول + نماذج المهام/الفروع؛ إن وُجدت شاشة حجوزات مخصّصة غير مربوطة بـ `/api/hub/platform-bookings` فقد تحتاج ربطًا لاحقًا.
- **موافقة إذن الموقع الحقيقية من المستخدم:** اختُبر مسار الرفض؛ الموافقة تتطلب متصفحًا تفاعليًا بإذن GPS.

## الحكم

رحلة **عميل → حفظ geo → دخول موظف اختبار → إعادة فتح البيانات → نماذج إدارة بدون كتالوج فروع** أثبتت على الإنتاج.

**لا أعلن FULL PASS مطلقًا لكل حسابات الموظفين الحقيقيين** لأن دخول Super Admin بمتغير البيئة ما زال غير متاح (بدون تغيير كلمة مروره).  
بالنسبة لنطاق الفروع المطلوب مع حساب الاختبار المحدود: **الرحلة مكتملة بنجاح**.
