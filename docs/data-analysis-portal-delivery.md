## 1) ما اكتشفته من النظام الفعلي

| البند | النتيجة |
|--------|---------|
| اسم النظام | **NAIOSH Intelligence** / «نايوش للتحليل» |
| عنوان التشغيل الحي | `https://www.naioshai.com/` |
| دخول المسجّلين | `https://www.naioshai.com/#login` → شاشة «تسجيل الدخول» |
| تسجيل جديد | الصفحة العامة → زر **إنشاء حساب** (لا يوجد `#register`) |
| نموذج كلمات مرور داخل هوب | **لا** |
| عملة باقات الشحن | **JOD / د.أ** (`commerce.currency: 'JOD'`) |
| نقاط الترحيب | **300** بعد تحقق البريد والجوال |

### كتالوج الخدمات (RD_SERVICES في الواجهة الحية)

| الخدمة | النقاط |
|--------|--------|
| تحليل ملف بيانات | 50 · حتى 40MB |

| دراسة جدوى مشروع جانبي | 200 |
| تقرير تنفيذي | 80 |
| تحليل الذات أنا 360 | 60 |

### باقات الشحن (packs)

| الباقة | النقاط | السعر (د.أ) |
|--------|--------|-------------|
| البداية | 100 | 9 |
| الأعمال | 300 | 24 |
| المؤسسات | 1000 | 69 |
| الشركاء | 3000 | 179 |

### ما لم أختلقه
- لا رابط تشعيبي وهمي للتسجيل
- لا محرك تحليل داخل هوب
- لا تعديل لبيانات العملاء / إعدادات الدفع / نظام النقاط في Intelligence

## 2) ما أُضيف في هوب

| ملف | الدور |
|-----|--------|
| `quality-analysis.html` | بوابة تسويقية كاملة (بطل، إجابات سريعة، خدمات، مزايا، خطوات، لقطات، نقاط، FAQ) |
| `css/hub-data-analysis.css` | تنسيق فاتح/داكن ومتجاوب |
| `js/hub-data-analysis.js` | ربط أزرار النظام/التسجيل/الدخول |
| `js/hub-live-systems.js` | تسجيل `ANALYSIS` |
| `assets/analysis/shot-*.png` | لقطات حقيقية (رئيسية، تسجيل، دخول، موبايل) |
| `index.html` | بطاقة/شعار التحليل ما زال يشير إلى `quality-analysis.html` |

## 3) الربط داخل هوب
- الرئيسية → شعار NAIOSH AI → `quality-analysis.html`
- لا توجد رسالة «المحتوى قيد التجهيز» في صفحة الفرع
