# تفعيل خرائط Google — خطوات بسيطة (بدون خبرة تقنية)

هذا الدليل لكِ حتى لو ما استخدمتي Google Cloud قبل كده.  
**مهم:** لا ترسلي أي مفتاح API في المحادثة أو في GitHub. حطّي المفاتيح فقط داخل Railway (الخطوات بالأسفل).

بدون المفاتيح: **كتابة اسم الفرع يدويًا تشتغل**، والخريطة تظهر «غير مفعّلة».  
**لا نعلن أن الخريطة شغّالة** إلا بعد التفعيل والاختبار على الموقع الحقيقي.

---

## هل فيه اشتراك أو تكلفة؟

| السؤال | الجواب البسيط |
|---|---|
| هل لازم اشتراك شهري ثابت؟ | **لا.** الدفع حسب الاستخدام (Pay as you go). |
| هل لازم بطاقة؟ | **نعم غالبًا.** Google يطلب ربط حساب فوترة (بطاقة) حتى لو الاستخدام قليل. |
| هل فيه استخدام مجاني؟ | **نعم.** لكل خدمة من خدمات Essentials تقريبًا **10,000 طلب مجاني شهريًا** (مثل تحميل الخريطة الديناميكية، والتحويل الجغرافي Geocoding). |
| هل هيدفع فوري؟ | لو عدد الزوّار قليل (آلاف قليلة شهريًا) غالبًا تبقين داخل الحد المجاني. فوق الحد يُحسب بالدولار حسب الاستخدام. |
| رابط الأسعار الرسمية | [Google Maps Platform Pricing](https://mapsplatform.google.com/pricing/) |

> ملاحظة: Google غيّرت نظام الخصم القديم ($200 شهريًا) إلى **حد مجاني لكل خدمة**. الأرقام أعلاه تقريبية لخدمات Essentials — راجعي صفحة الأسعار لأنها قد تتحدّث.

## الجزء أ — من Google Cloud (مرة واحدة)

### 1) افتحي Google Cloud
1. ادخلي من جهازك: [https://console.cloud.google.com/](https://console.cloud.google.com/)
2. سجّلي بحساب Google الخاص بالمشروع (يفضّل حساب الشركة).

### 2) أنشئي مشروعًا
1. من أعلى الصفحة اختاري **Select a project** → **New Project**.
2. الاسم مثلًا: `naiosh-hub-maps`.
3. اضغطي **Create** وانتظري حتى يجهز.

### 3) اربطي الفوترة (Billing)
1. من القائمة: **Billing** → اربطي المشروع بحساب فوترة.
2. لو أول مرة: أكملي بيانات البطاقة كما يطلب Google.
3. هذا **لا يعني** أنكِ هتُخصم فورًا — لكنه مطلوب لتفعيل Maps.

### 4) فعّلي خدمتين فقط
من القائمة: **APIs & Services** → **Library**، ثم ابحثي وفعّلي:

1. **Maps JavaScript API** → Enable  
2. **Geocoding API** → Enable  

لا تحتاجي تفعيل كل شيء.

### 5) أنشئي مفتاح المتصفح (للخريطة في الموقع)
1. **APIs & Services** → **Credentials** → **Create credentials** → **API key**.
2. انسخي المفتاح في مكان آمن مؤقتًا (مذكرة خاصة بكِ) — **لا تلصقيه هنا في الشات**.
3. اضغطي **Edit API key** (أو Restrict key):
   - **Name:** `naiosh-browser-maps`
   - **Application restrictions:** اختاري **HTTP referrers (web sites)**
   - أضيفي هذه السطور (كل سطر referrer):
     - `https://naiosh-hub-production.up.railway.app/*`
     - `https://www.naioshai.com/*` (لو الدومين شغال عندك)
     - `http://localhost:*/*` (للتطوير فقط إن احتجتِ)
   - **API restrictions:** اختاري **Restrict key** → علّمي فقط **Maps JavaScript API**
4. احفظي **Save**.

هذا المفتاح اسمه عندنا في السيرفر: `GOOGLE_MAPS_BROWSER_KEY`

### 6) أنشئي مفتاح الخادم (للتحويل الجغرافي — سرّي)
1. من نفس صفحة Credentials → **Create credentials** → **API key** مرة ثانية.
2. **Edit API key**:
   - **Name:** `naiosh-server-geocode`
   - **Application restrictions:** اختاري **None** مؤقتًا (أو IP لو عرفتي عناوين Railway لاحقًا)
   - **API restrictions:** **Restrict key** → علّمي فقط **Geocoding API**
3. احفظي.

هذا المفتاح: `GOOGLE_MAPS_SERVER_KEY`  
**لا يظهر أبدًا في المتصفح** — السيرفر فقط يستخدمه.

## الجزء ب — ضعي المفاتيح في Railway (بدون إرسالها لي)

1. افتحي [Railway Dashboard](https://railway.app/dashboard) وسجّلي الدخول.
2. اختاري مشروع نايوش هوب → خدمة **`naiosh-hub`** (خدمة التطبيق، مش Postgres).
3. تبويب **Variables**.
4. أضيفي متغيرين (Raw / New Variable):

| الاسم | القيمة |
|---|---|
| `GOOGLE_MAPS_BROWSER_KEY` | مفتاح المتصفح من الخطوة 5 |
| `GOOGLE_MAPS_SERVER_KEY` | مفتاح الخادم من الخطوة 6 |

5. احفظي — Railway عادةً يعيد النشر تلقائيًا. انتظري حتى يصير Deploy **Success**.
6. **لا تلصقي المفاتيح في الشات.** فقط اكتب لي:  
   **«تم وضع المفاتيح في Railway»**  
   وأنا أتحقق من التفعيل بنفسي عبر فحص عام (بدون قراءة المفاتيح).

## الجزء ج — ماذا أفعل أنا بعد ما تقولي «تم»

1. أتحقق: `GET /api/hub/geo/config` على الإنتاج → لازم `mapsEnabled: true`.
2. أختبر على الموقع الحقيقي:
   - كتابة اسم الفرع يدويًا
   - تحديد الموقع بعد الموافقة
   - اختيار نقطة على الخريطة
   - ظهور البلد/المدينة والتعديل قبل التأكيد
   - الإكمال اليدوي عند رفض الإذن أو تعطّل الخريطة
   - الحفظ وإعادة فتح الطلب
3. أكمل اختبار الهوية والإعلانات في لوحة الموظف.
4. **FULL PASS فقط** بعد نجاح الخرائط + الحفظ/إعادة الفتح على الموقع الحقيقي.

## تحقق سريع يمكنكِ عمله بنفسك (اختياري)

بعد نجاح Deploy، افتحي في المتصفح:

`https://naiosh-hub-production.up.railway.app/api/hub/geo/config`

المتوقع عند النجاح تقريبًا:

```json
{
  "mapsEnabled": true,
  "browserMapsEnabled": true,
  "geocodeEnabled": true
}
```

- ظهور `browserKey` في هذه الاستجابة طبيعي (مفتاح متصفح مقيّد بالـ referrer).
- مفتاح الخادم **لا يظهر** هنا أبدًا — لو ظهر فهو خطأ ويجب تدويره فورًا.
