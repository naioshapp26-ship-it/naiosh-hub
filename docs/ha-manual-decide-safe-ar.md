## الخطوات (واجهة الإنتاج)

1. افتح `https://naiosh-hub-production.up.railway.app` وسجّل دخولك كـ **مدير أعلى / Super Admin** (جلسة خاصة بك).
2. ادخل **صندوق الموافقات العليا / Higher Approvals**.
3. افتح `APR-2026-00079` → **موافقة / Approve** → تأكيد.
4. افتح `APR-2026-00080` → **رفض / Reject** → اكتب سببًا قصيرًا (مثل: `اختبار رفض الإطلاق`) → تأكيد.
5. تحقق بصريًا:
   - المنحة المرتبطة أصبحت مفعّلة.
   - الإيجار أصبح مرفوضًا.
   - إعادة الضغط على قرار سابق لا تعيد التنفيذ.
6. في محادثة الوكيل اكتب **فقط**:

```text
HA done: APR-2026-00079 approved; APR-2026-00080 rejected
```

## ماذا يفعل الوكيل بعدها (بدون كلمة مرورك)

يشغّل `scripts/verify-ha-manual-targets.js` بحساب موظف اختبار محدود الصلاحية للتحقق من:

- حالة الطلبين في API
- آثار الأصل (منحة/إيجار)
- رفض إعادة القرار بدور ADMIN (403)

لن يُسجَّل PASS قبل نجاح هذا التحقق.

## بديل (اختياري)
