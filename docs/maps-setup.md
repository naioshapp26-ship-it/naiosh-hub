# خرائط نايوش هوب — الخدمة الافتراضية والبدائل

## الخدمة المستخدمة حاليًا (بدون مفاتيح)

| الطبقة | التقنية | تكلفة مباشرة |
|---|---|---|
| عرض الخريطة التفاعلية | **Leaflet 1.9** + بلاطات **OpenStreetMap** | بدون مفتاح API |
| التحويل الجغرافي (بلد/مدينة من الإحداثيات) | **Nominatim** عبر خادم نايوش (`/api/hub/geo/reverse`) مع حد معدّل (~1 طلب/ث) وتخزين مؤقت | بدون مفتاح |
| بديل اختياري | **Google Maps** + Geocoding إن وُجدت `GOOGLE_MAPS_*` | حسب استخدام Google |

الكتابة اليدوية لاسم الفرع/البلد **دائمًا متاحة** حتى لو تعطّلت الخريطة أو رُفض إذن الموقع.

## شروط الاستخدام / التوسّع

- بلاطات OSM وNominatim العامّان مناسبان للاستخدام التشغيلي المتوسط مع الالتزام بسياسة الاستخدام (User-Agent واضح، عدم الإفراط).
- عند نمو المنصة بقوة يُفضّل:
  - مفاتيح Google (`docs/google-maps-setup.md` سابقًا)، أو
  - مزوّد بلاطات مدفوع (MapTiler / Mapbox) + Nominatim ذاتي الاستضافة.

## التحقق

```
GET /api/hub/geo/config
```

المتوقع بدون Google:

```json
{
  "mapsEnabled": true,
  "leafletEnabled": true,
  "provider": "osm-leaflet",
  "geocodeProvider": "nominatim"
}
```
