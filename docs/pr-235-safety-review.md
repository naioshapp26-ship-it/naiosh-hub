# مراجعة سلامة PR #235 — باقات / Paymob

## الخلاصة
**آمن للدمج من ناحية المحفظة وبيانات العملاء وصلاحيات الإدارة** مع ضوابط Test/Live.  
**لا FULL PASS إنتاجي** قبل اختبار Test على الموقع المنشور ثم موافقة Live.

| المجال | الحكم |
|---|---|
| شكل المحفظة `{paid,free,total,ledger}` | لم يُكسر — إضافات اختيارية على قيود السجل فقط |
| بيانات العملاء | `readStore` أصبح يحفظ `packageOrders` / أسعار النقاط / التدقيق (إصلاح فقدان سابق) |
| صلاحيات الإدارة | كل `/api/admin/packages/*` عبر `requireStaff`؛ التعديل/الاسترداد يحتاج `wallet.adjust` (أو صلاحيات موثّقة سابقة للتأكيد) |
| إضافة نقاط مدفوعة | فقط بعد HMAC موثوق أو تأكيد إداري مصرّح — Stub ممنوع على production-like |
| Live | لا يُفعّل بدون `HUB_PAYMOB_LIVE=1` + `HUB_PAYMOB_MODE=live` |

## ما زال خارج FULL PASS
- رحلة دفع Test على الإنتاج بمفاتيح تاجر حقيقية (بعد وضعها في Railway دون مشاركتها هنا)
- موافقة المالك قبل Live
