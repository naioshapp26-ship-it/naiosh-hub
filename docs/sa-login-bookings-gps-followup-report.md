# تقرير — ثبات الحجوزات (استعادة تجريبية ملغاة)

## قرار
استعادة الحجوزات التجريبية: **ملغاة**. لا تشغّل `HUB_SAFE_RESTORE_*` على Railway.  
Hook الاستعادة عند الإقلاع: **أُزيل**.

## هل يمكن دمج PR #229 بأمان؟
**نعم** — لدمج إصلاح منع الفقدان فقط، طالما لا يُضبط أي متغير استعادة.

| جزء في الـ PR | أثر عند الدمج بدون متغيرات |
|---|---|
| دمج hydrate (ملف ∪ Postgres حسب id) | يُفعَّل — هذا الإصلاح المطلوب |
| سكربتات/مكتبة الاستعادة | لا تعمل بدون علم صريح؛ السكربت مرفوض افتراضيًا |
| تشخيص SA / GPS | أدوات فقط — لا تغيّر بيانات |

## الحكم

- ثبات عبر إعادة تشغيل العملية: **مثبت محليًا مع Postgres**.
- على الإنتاج: الحفظ/إعادة الفتح يعملان الآن؛ **لا PASS لثبات ما بعد إعادة النشر حتى يُدمج الإصلاح ويُعاد التحقق**.
