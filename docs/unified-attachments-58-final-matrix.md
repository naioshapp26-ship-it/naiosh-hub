# الجدول النهائي للنماذج الـ58 — مرفقات نايوش هوب 360

تاريخ: 2026-10-12 · الفرع: `cursor/unified-attachments-full-audit-ee32` · PR #216  
**لا يُعلن FULL PASS** — انظر أعمدة النتيجة واختبارات الإنتاج.

### مفاتيح النتيجة
- **PASS** = وظيفة مؤكدة بالكود + اختبار مناسب حيث ذُكر
- **PARTIAL** = وسائط موجودة لكن ينقص multi/معاينة/تقدم/persist كامل
- **REDIRECT** = النموذج السريع يوجّه لصفحة كاملة فيها الرفع
- **NOT_TESTED** = لم يُختبر بالمتصفح/الإنتاج بعد
- **EXCEPTION** = استثناء وظيفي موثّق (مثال: شعار متجر = صورة فقط)

### اختبارات البنية التحتية (منفصلة)
| البند | النتيجة |
|---|---|
| رفع مجزأ + استئناف | **PASS** عند 6MB و**100MB** · **NOT_TESTED** عند 500/1000/1500 |
| سلم الأحجام **100 / 500 / 1000 / 1500MB** | **PASS محلي** (اكتمال + سلامة بايتات + بقاء بعد إعادة تشغيل عند 100/500/1500) |
| رحلات إنتاج متعددة الأدوار + جوال + ليلي على النسخة المنشورة لهذا الفرع | **NOT_TESTED** |
| صحة الإنتاج `/api/health` | **PASS** (سابقاً) |
