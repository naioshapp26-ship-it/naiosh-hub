## 2) ما أُصلح في هذه المرحلة (بدون نظام موازٍ)

1. توسيع `ENTITY_TYPES` ليشمل: `support`, `ticket`, `complaint`, `booking`, `freelancer`, `side_project`, `research`, `article`, `event`, `campaign`.
2. `HubFormAttachments.upgradeForm` + `softPersistToEntity` (حفظ دائم عند وجود جلسة؛ للضيف يُوثَّق `login_required`).
3. خدمات/استشارة/مقترح/شكوى/دعم → واجهة متعددة + persist/reopen عند تسجيل الدخول.
4. فريلانسر / حجز / مشاريع جانبية → HFA + 1500MB + softPersist.
5. متجر: منطقة فيديو + رفع عبر HubUploadLimits بدل dataURL فقط.
6. فعاليات: رفع متعدد + ربط EA.
7. بوابة عميل: شريط تقدم XHR.
8. ملف 360: كتلة HFA متعددة + حفظ وثائق + EA `identity`.
9. HubActions: حد 1500MB في التسميات.
