# جرد نماذج المرفقات — نايوش هوب 360

تاريخ الجرد: بعد توحيد مكوّن `HubFormAttachments` + `/api/hub/entity-attachments`.

## المكوّن الموحّد
- `js/hub-form-attachments.js` — عنوان **المرفقات** · رفع صورة / ملف / فيديو · متعدد · معاينة · إزالة · تقدم · إعادة محاولة
- `js/hub-upload-limits.js` — حد **1500 ميجابايت** للملف مع XHR progress
- `lib/hub-entity-attachments.js` + `POST/GET/DELETE /api/hub/entity-attachments` — ربط دائم بمالك السجل

## حالة النماذج (ملخص)

| النموذج | الحالة | ملاحظة |
|---|---|---|
| إضافة/تعديل موظف (فريق العمل والصلاحيات) | **موحّد** | `hto-employee-attachments` + entityType=employee |
| عرض ملف الموظف (درج التفاصيل) | **موحّد** | تحميل قائمة المرفقات |
| إضافة موظف (Workforce) | **موحّد** | استبدال رابط الصورة |
| إضافة/تعديل إداري (Staff Admin) | **موحّد** | entityType=staff |
| خدمات / استشارات / شكاوى / اقتراحات / دعم | **موحّد سابقًا** | HubFormAttachments |
| التسجيل / الحجز / المشاريع الجانبية | **رفع مخصص** | HubUploadLimits — متوافق مع الحد |
| استوديو الفعاليات / التسويق / المقالات | **رفع مخصص** | موجود |
| بوابة العميل (تذاكر/طلبات) | **مخصص دائم** | `/api/client/attachments` |
| حلول نايوش (wizard) + خفض التكاليف | **موحّد** | `#so-wizard-attachments` + entityType=solution |
| Identity UI (إضافة/تعديل مستخدم) | **موحّد** | `#idn-user-attachments` + entityType=identity |
| إدارة العملاء (إنشاء/تعديل) | **موحّد** | `#cl-attachments` + entityType=client |
| صفحات الدخول/الدفع/النشرة | لا ينطبق | لا مرفقات |

## الأمان
- العميل لا يرى مرفقات موظف/إداري عبر تخمين entityId (فلترة ownerEmail لغير الموظفين)
- Idempotency-Key يمنع تكرار المرفق عند إعادة الإرسال
- الحذف ناعم (status=deleted) مع فحص صلاحية

## حد 1500MB
- السياسة والكود يدعمان 1500MB مع رفع متدفق + شريط تقدم
- الرفع المجزأ المستأنف عبر Object Storage يحتاج تفعيل backend خارجي عند توفره؛ حتى ذلك الحين الرفع يتم كبثّ متصل مع إعادة محاولة من الواجهة
